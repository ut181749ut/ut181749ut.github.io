# 一言日記

1日1行、30秒で終わる日記アプリです。1年たつと「去年の今日」の一言が出てきます。

ブラウザで開くだけで使えます。スマホなら「ホーム画面に追加」すると、アプリと同じように使えます。

## できること

- **1日1行**：書けるのは1日50文字まで。その日のうちなら書き直せます
- **これまでの「今日」**：去年や2年前の同じ日の一言が並びます
- **写真**：1日1枚、写真をつけられます（自動で縮小して保存）
- **カレンダー**：書いた日に色がつき、写真のある日は写真が出ます。書き忘れた日もあとから書けます
- **テーマ**：生成り・夜・桜・若葉・海の5色
- **1年のまとめ（有料）**：1年分の一言を、画像1枚やPDFにまとめます

一言と写真は、その端末のブラウザの中（IndexedDB）だけに保存されます。サーバーには送りません。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面 |
| `style.css` | 見た目とテーマ |
| `app.js` | 動き（保存・カレンダー・まとめなど） |
| `config.js` | 値段・決済ページ・購入コードの設定 |
| `sw.js` | オフラインでも開けるようにする仕組み |
| `manifest.webmanifest`, `icons/` | ホーム画面に追加したときの名前とアイコン |

ビルドは不要です。このフォルダをそのまま GitHub Pages などに置けば動きます。

## 手元で動かす

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 有料機能（1年のまとめ）の設定

`config.js` で設定します。

1. 決済サービス（Stripe の Payment Link など）で商品を作ります
2. 決済が終わったときの戻り先を `https://<公開先のURL>/?unlock=<購入コード>` にします
3. その決済ページのURLを `paymentUrl` に書きます

購入コードを変えるときは、新しいコードのハッシュを `unlockCodeSha256` に書きます。

```sh
printf '%s' 'HTK-あたらしいコード' | sha256sum
```

> **注意**：この仕組みは、サーバーを使わない簡単な鍵です。ブラウザの開発者ツールを使えば、お金を払わずに開けられてしまいます。
> ちゃんと課金するなら、Google Play に出すときに Google Play の課金に切り替えるか、購入を確かめるサーバーを用意してください。

## 更新するとき

`sw.js` の `VERSION` を上げると、すでに使っている人にも新しい版が届きます。
